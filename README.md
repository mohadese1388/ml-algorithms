# Machine Learning Algorithms Project

This repository contains a practical implementation and study of several classical machine learning algorithms using Python and Scikit-learn.

The main goal of this project is to understand the basic concepts behind machine learning models, data preprocessing, model training, prediction, and performance evaluation.

## Algorithms

The following algorithms and techniques are covered in this project:

- **K-Nearest Neighbors (KNN)**
- **Decision Tree**
- **Random Forest**
- **Principal Component Analysis (PCA)**

## Project Features

- Loading and preparing datasets
- Data preprocessing
- Splitting data into training and testing sets
- Training machine learning models
- Making predictions
- Evaluating model performance
- Comparing different algorithms
- Reducing data dimensions using PCA
- Visualizing results where applicable

## Technologies and Libraries

This project is developed using Python and the following libraries:

- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
